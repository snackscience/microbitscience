📖 마이크로비트 X 바이브코딩 실험 연결 방법

1단계. MakeCode 코드 열기 및 편집
홈 화면 또는 실험실 상단의 🧩 MakeCode 코드 버튼을 클릭한 뒤, MakeCode 페이지 우측 상단의 편집 버튼을 누릅니다.
2단계. USB 유선 연결 및 다운로드
마이크로비트를 USB 케이블로 컴퓨터에 연결하고, MakeCode 화면 하단의 연결 (기기 페어링) → 다운로드를 눌러 실험용 프로그램을 마이크로비트에 심어줍니다.
3단계. 배터리 연결 후 무선 상태에서 프로그램 연결
USB 케이블을 뽑고 마이크로비트 배터리 팩을 연결해 무선 상태로 만듭니다.
그다음 바이브코딩 실험실 상단의 마이크로비트 연결 버튼을 눌러 기기를 선택하면, 별도 버튼 조작 없이 즉시 실시간 데이터 수집이 시작됩니다!
4단계. AI 분석 및 내 계정에 기록 보관
실험이 끝나면 [일시정지] 또는 [✨ AI 분석] 버튼으로 결과 리포트를 확인하고, 로그인 상태에서 [💾 기록 저장]을 누르면 언제든 [📂 내 기록]에서 다시 볼 수 있습니다.
